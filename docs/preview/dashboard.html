Programas — a forma do trabalho

Cada programs/*.yml é um grafo: nós são steps, arestas são dependências. Aresta cheia = dado atravessa (${steps.X}); tracejada = só ordem de execução; vermelha = declarada com depends_on mas nada atravessa (espera possivelmente desnecessária).

Limpeza de disco

Escaneia worktrees mergeados, node_modules órfãos/antigos e caches parados — nunca deleta sozinho. Antes de sugerir qualquer remoção, verifica se o diretório contém arquivos não versionados de segredo (.env, chaves, credenciais); se contém, exige confirmação nomeada separada em vez de remover junto com o resto.
